# 运营SOP与Codex任务卡 V1.0

## A. 第一个月经营验证

以单店、桌面理线/工具收纳/家庭维修配件三个待研究方向举例（不代表已验证蓝海）。预算建议4000元，按真实店铺资质和费用调整；优先控制风险而非销量。

| 周 | 业务行动 | 输出 / 验收 |
|---|---|---|
| 1 | 选一个主场景；获取授权关键词样本、记录真实平台可见字段；收集约100个种子词 | 关键词池、权限矩阵、10个待核验机会；无授权数据则人工研究 |
| 2 | 对比同SKU零售价格，询1688代发报价、运费、售后；核算正常及压力利润 | 约20个候选、3–5个优先样品；未通过风险闸门不进下一步 |
| 3 | 样品检查、主备供应商、原创/授权素材、合规审核；小批上架 | 5–10个以内实验商品（样品合格才上架）；每个有预算和停止条件 |
| 4 | 记录曝光、点击、支付、退款、广告；按成熟订单与实际成本复盘 | 继续/优化/暂停/不确定；保留失败原因和分数版本 |

预算：保证金及相关费用预留1000、样品500、工具200、测款推广500、代发周转1000、应急800；实际保证金及收费待账号核验。任何单品先设可承受损失上限，禁止刷单、虚假评价、虚构库存及未经许可的素材搬运。

### 日常流程（30–60分钟，按经营情况调整）

- 每日：检查待发货、缺货、质量/退款异常、预算和现金占用；核验主供报价是否有效；更新成熟订单贡献与待结算金额。
- 每周：复查候选词趋势、同款价格带、主备供货条件；新增3–5个候选、淘汰证据明确不合格的商品；比较同渠道CTR和支付转化率，记录主图/价格/投放变更。
- 每月：按SKU统计实际贡献/支付订单、退款成熟率、广告成本、履约时效；对评分区间实际效果进行比较，不用未来数据补入历史特征；修订策略版本。

### 供货询问清单

1. 指定型号、尺寸、材质、数量、颜色是否支持单件代发？报价是否包含包材及运费？偏远地区如何计费？
2. 常规与节假日发货时效？库存如何同步？缺货、错发和超时如何处理？
3. 是否支持符合平台规则的包装和发货？是否提供品牌/素材授权、必要质量文件？
4. 退货地址、质量问题运费、采购款可退额度、换货费用？报价有效期？
5. 样品能否按真实消费者订单方式发出？记录到货时间、质量、包装、SKU及售后沟通。所有约定留存证据。

### 单品测款记录

开始日/截止日；假设（目标人群、场景、差异化）；预算、止损；主图/标题/价格版本；供应商与报价；按流量渠道记录曝光、点击、支付；全退及部分退、广告实际扣费；成熟订单贡献；结果与原因。初始观察目标7–14日/100有效点击，预算或安全风险优先停止，样本不足标“不确定”。不因单笔订单盈利便直接放量。

## B. Codex 可执行任务卡

每卡须有测试、文档及示例；依赖满足后执行。`D00` 的真实外部授权验证由人完成，Codex只能辅助字段分析。建议小批提交、人工验收；首版不开发自动下单。

| 任务 | 依赖 | 实现范围 | 验收 |
|---|---|---|---|
| D00 数据验证 | 无 | 收集授权导出样本；权限矩阵、真实字段、费用、刷新限制 | 至少一份可合法使用的关键词/价格/货源样本；缺项写明，不阻塞人工录入 |
| D01 工程骨架 | 无 | Compose、FastAPI、Vue、Postgres、配置、健康检查、CI | 一条启动命令；迁移、lint、测试、前端首页通过 |
| D02 导入管道 | D01 | 来源、批次、CSV列映射、验证、预览、错误报告 | 20行样例、重复哈希、比例/日期错误及部分成功测试 |
| D03 关键词策略 | D02 | 7/30日趋势、机会比、三值规则、快照 | 零分母/缺字段/口径冲突单测；模拟候选可重跑 |
| D04 商品与SKU | D02 | SPU/SKU、平台链接、匹配审核、报价聚合 | 1件和10件不可比；同规格价格中位数可复算 |
| D05 供应链 | D04 | 供应商、报价、时效、样品证据及主备 | 未核验货源不可进入测款；样品失败阻断 |

| D10 部署与验收 | D09 | 安全、备份恢复、日志、基准、端到端 | 从导入到复盘完整链路，恢复测试，真实样本小规模试运行 |
| D11 AI报告 P1 | D10 | 模型适配、提示词、Schema、证据校验、缓存、降级 | 伪证据拒绝、超时降级、恶意评论无工具执行 |
| D12 授权接口 P1 | D00,D10 | 单个平台只读 adapter、配额、失效回退 | 账号授权确认；真实调用与导出结果对账；撤权停止 |
| D13 监控预警 P1 | D10,D12 | 定时刷新、价格/库存/利润过期预警 | 不重复提醒；处理关闭与证据可查 |

## C. 验收测试清单

| ID | 测试 | 预期 |
|---|---|---|
| T01 | 相同来源/文件/映射重复导入 | 同批次幂等，无双计 |
| T02 | 比例写成8而非0.08；负价；时间窗口倒置 | 拒绝并返回行号和错误原因 |
| T03 | 搜索人气存在、链接数为0 | 机会比未知，不显示无限大 |
| T04 | 已售1000+与评价1000 | 不横向计算销量和集中度 |
| T05 | 不同材质或件数的相似图 | 硬冲突不匹配 |
| T06 | 券价有资格限制或报价过期 | 不当成可直接成交价格 |
| T07 | 经济性6组边界样例 | Decimal精确、展示HALF_UP |
| T08 | 评分80分但样品失败 | BLOCKED，不能进入测款 |
| T09 | 完整度90%、关键字段未知 | NEEDS_EVIDENCE，只有区间 |
| T10 | 旧配置重算历史候选 | 快照、权重、结果不变 |
| T11 | 重复订单、部分退款、全退、广告分配 | 不重复计算，按支付日归属，成熟单单列 |

## D. 上线门禁

D00 有真实权限和字段记录；D01–D10 全部关键用例通过；风险闸门与人工操作生效；真实商品至少跑通一次样品审核、合法上架及订单复盘；未获得足够订单样本不宣称策略有效。SaaS、多平台自动化、自动采购支付另立项目评估。
