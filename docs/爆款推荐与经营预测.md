# 爆款推荐与经营预测

从左侧 **爆款推荐** 进入。研究优先级由当前需求证据、已核验的正向经济性和可比报价决定，评分用于辅助排序。「下一步」按候选阶段和样品、风险审核显示可执行动作。点「查看依据」可补关键词、主供或报价。平台的已售、已拼、评价和搜索指数保留各自口径。实际成交需求由测款验证。

## 试算定价、成本与资金

1. 在候选行点 **定价预测**，或从比价报告点 **继续定价预测**。检查采购方式、报价地区、成交单价与成本。备货将批量货款和进货运费按整套可售库存分摊。代发把供应商直发运费计入每单发货费。
2. 填每单固定平台费和按实付金额收取的费率。目标贡献率以实付收入为分母。结果包括盈亏平衡价、目标最低价、采购到手成本上限和广告费上限。竞品到手价低于目标价时，显示差额及按该价达到目标需要节省的每单成本。
3. 填写预测期、日均有效访问或点击以及三档支付转化率。已结束且渠道与订单账本对齐的测款可带入历史点击基准。可另填两个备选售价，各自填写转化率。备货按可售库存限制履约订单并显示余货，代发按每日可履约量限制订单。库存或产能未知时结果标注为未受容量约束的需求试算。
4. 备货资金为首批货款及入库运费加投放预算和退款准备金。代发以结算周期内预计前置垫付订单数乘采购、发货和包材服务费，再加预算和准备金。主要参数未知时资金需求留空。部分退款用独立的「预计退款额占支付收入」比例估算净收入。
5. 点 **保存预测方案** 为当前假设保存独立版本。可以查看已保存方案或调整参数后另存。选择有候选、完整费用、渠道和三档流量的方案，点 **采用到测款**。按北京时间整日填写起止日期，天数和预测期一致。创建及开始时复核当前证据和采购口径，进行中的测款保留原方案。

## 预测及实际口径

设实付单价为 P，按实付金额的费率为 k，全退概率为 r。每支付订单期望贡献为 `(1−r)×(P×(1−k)−采购到手−发货运费−包材服务费−固定平台费)−r×全退净损失−广告费`。全退净损失已扣回收款且不包含广告。预计支付收入为预计履约订单乘 P。填写预计退款金额比例后，预计净收入等于支付收入减预计退款金额。预计净收入和贡献分别按各自口径展示。

在 **测款计划 → 查看 → 预测与实际对照** 查看同渠道、同窗口的基准与实际。订单以数据来源和支付单标识去重。成熟贡献只统计所有商品明细均成熟、已结算、费用完整的支付订单。流量口径一致时可以比较转化。广告或明细缺失会提示继续对账。结束且对账齐全后展示偏差。可从原方案另存下轮假设。

模拟演示的基准为 30 天、日均 200 次有效访问、转化率 4%、成交单价 ¥49.90。未受库存限制时预计支付 240 单，支付收入 ¥11,976.00，贡献 ¥5,507.52。按演练费率和成本，目标贡献率 20% 的最低售价为 ¥31.89，计划价下的采购成本上限为 ¥29.09。

## 接口与版本

- `GET /api/v1/opportunities` 提供推荐列表，`/opportunities/baseline` 带入当前报价或候选成本，`POST /opportunities/forecast` 即时试算。
- `POST /api/v1/forecasts` 保存方案，`GET /api/v1/forecasts` 和 `GET /api/v1/forecasts/{id}` 查阅记录。传入 `parent_forecast_id` 可另存新版本，`GET /api/v1/forecasts/{id}/replay` 用已保存输入和价格基准复算。
- `GET /api/v1/forecasts/traffic` 返回已对齐的自有点击基准。测款计划使用可选的 `forecast_id`，复盘结果随 `GET /api/v1/experiments/{id}/summary` 返回。
- 已保存的预测假设、证据版本和计算结果随数据库备份。模拟演示、公开历史和真实经营数据各自保留。
