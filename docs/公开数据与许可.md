# 公开数据与许可

默认公开真实样本来自 UCI 官方 [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail)。署名：Chen, D. (2015). Online Retail [Dataset]. UCI Machine Learning Repository. DOI: 10.24432/C5BW33。数据许可为 CC BY 4.0，使用或分发派生样本时保留此出处、许可和修改说明。

原文件覆盖2010年12月到2011年12月的英国零售交易，字段包括发票、商品编码、描述、数量、时间、英镑单价、客户标识和国家。本项目不保留客户标识，按原行号记录出处，转换来源时区后保存时间，不增加虚构采购/广告成本。

下载脚本固定官方HTTPS地址，记录并核验原文件 SHA256。当前摘要为 `f5385cbb54bbebf7196389109c6b0621faab0c304e3702548165e71c84aede8b`。已锁定文件如摘要变化，脚本停止，要求审查。准备批次和控制总量见 `data/public_manifest.json`。

当前5000行样本对账：数量45929，交易金额GBP 102189.24，72条取消/负数量记录保持未匹配。软件不将取消记录擅自关联到原订单，不把历史取消率当作当前全退概率。金额是历史交易记录的算术合计，不是当前店铺净收入或利润。

全量原文件、生成的大批次不提交Git。测试夹具为固定、脱去客户标识的真实摘录，仍保留原始行号及署名。模拟电商关键词、报价、样品和经营记录由代码合成，始终在demo空间。

调研中找到的淘宝研究数据包含限制商业用途的许可；Amazon Reviews 2023 的代码许可不能直接视作数据商业使用许可。因此二者未内置，未将GitHub镜像存在视作授权。当前没有获得用户商家后台或淘宝/1688实时API权限，不承诺当前全网数据。
